# Obsidian 代码阅读

## 先修文档本身

明确 Python、Scheme、SQL、Bash 等语言；纯输出、结构示意和伪代码不强行套成可运行 Python。`>>>` 交互会话可用 Python 高亮，但说明提示符及结果行不应直接粘进脚本。保留代码正文与缩进，只调整语言标签和排版元数据。

先比较 Obsidian 内置高亮和现有插件，不重复安装。对用户已要求的代码阅读增强，优先挑一个支持阅读视图、语言标记、复制、长行处理且平台合适的成熟插件。

可核对的候选：

- [Codeblock Customizer](https://github.com/mugiwara85/CodeblockCustomizer)：行号、语言标签、缩进线、复制和换行等。
- [Code Styler](https://github.com/mayurankv/Obsidian-Code-Styler)：编辑和阅读视图的代码样式、行号、标题等。

功能、版本、维护状态和兼容性在执行时查看官方仓库与社区市场；不要把旧版本设置结构当作当前 API。仅需基本显示时不叠加两个代码块渲染器，不安装运行代码插件。

## 推荐起点，可按用户偏好调整

- 保持当前全局明暗主题；显示行号与语言，复制按钮容易找到。
- 编程课显示缩进辅助线；长行可换行，并保留切换为横向滚动的选项。
- 默认完整展开，不因长代码自动隐藏后半段；避免误点标题导致整块折叠。
- 字号略接近正文、行距舒适，保留等宽字体和真实缩进；不要通过插入行号污染代码文本。
- 阅读输出与源码应可区分；关闭插件后仍能阅读标准 Markdown。

通过插件设置完成插件已有能力。少量排版修正集中到一个书页专用 CSS 片段，不修改全局主题。可从 [course-code-reading.css](../assets/course-code-reading.css) 起步，在本次生成书页的 frontmatter 中添加 `cssclasses: [course-book]`；已有 cssclasses 应合并，不能覆盖。

样式片段的创建不等于已启用。只有在实际笔记库中成功启用后才报告生效，打开包含代码的代表页检查字号、高亮、缩进、长行和按钮。不要为样式检查运行教材程序。用户不需要时，不为了“优化”顺带改安装、同步或其他笔记库配置。

有 purpose-built 工具或可靠 CLI 时优先使用；否则通过现有计算机使用工具操作 UI。编辑插件数据文件前先核对该版本源码/实际配置结构，避免与运行中的配置互相覆盖。不要关闭用户的原有阅读标签页。

## 便携性

文件打包可以附 CSS 片段与简短启用说明；不把库的全部 `.obsidian`、私有设置和插件代码塞进课程 ZIP。另一台设备可能要单独启用插件和样式；不要声称手机端已验证，除非确实检查过。
